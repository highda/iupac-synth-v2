# Design decisions

Decision register, issued 2026-09-15 and amended as the product grew. **Fixed** decisions change only through the procedure at the end of this document. **Latitude** entries bound implementation choices that may change with recorded evidence. **Provisional** entries were calibration experiments. New work must be entailed by these contracts, repair a demonstrated defect, or implement an evidence-backed correction.

## Register

| ID | Kind | Decision / boundary |
| --- | --- | --- |
| A1 | fixed | Complete manual modular polyphonic instrument and V0 before chemistry/discovery implementation. Chemistry OFF includes module/edge/matrix authoring, MIDI/macros, presets/state and production render/inspection. |
| A2 | fixed | Validated molecular identity → Analysis → synth-independent SonicIntent plus structural detail → generator → ordinary public Patch. No fixed recipes/lanes, top-N/softmax identity, descriptor→DSP bypass, or hash-manufactured audible distinction. |
| A3 | fixed | Finite registered module catalog and bounded editable DAG/matrix, compiled off audio into bounded values. Preserve Patch v1's seven types, 3 envelopes/2 LFOs and current parameter IDs/arities as this release's compatibility envelope; the node/edge/row caps are 11/32/24 since D6 (originally 8/16/16), and these numbers are not universal synth design laws. Capacity increases/new module features require a demonstrated requirement/correction. |
| A4 | fixed | One production codec/validator/compiler/matrix interpretation/engine for manual, factory, generated, CLI, plugin and tests. Shared rendering is allowed to use JUCE; framework independence is not an end in itself. |
| A5 | fixed | Audio exclusively owns mutable runtime state; bounded preallocated storage, no audio allocation/free/locks/I/O/chemistry/reclamation. Off-thread compilation; note-preserving scalar/matrix edits; bounded structural crossfade/retrigger with at most two active banks and latest-generation publication. No stale asynchronous author may overwrite a newer edit/load. |
| A6 | fixed | Eight generic host IDs/ranges in ARCHITECTURE; four macros route only through matrix. Exact base/edited Patch and controls persist separately from optional provenance and ephemeral DSP. Preset/project load restores exact stored sound without discovery/helper/remapping. No host memory-offset mirror or dynamic host schema. |
| A7 | fixed | V0–V11, authored/broad/hard/holdout panels and independent expected chemistry assertions. Objective gates do not prove musical quality; human evidence stays precise and separate. No available automatic gate waiver. |
| A8 | fixed | Canonical Debian 12 arm64 targets. Full install is offline/self-contained; private chemistry runtimes outside host audio process. |
| A10 | fixed | Required optional-to-use molecular browser: bounded distributable offline common-name/synonym collection, explicit ambiguity and provenance, backend structure validation, disposable cache, ordinary file presets. No mandatory runtime network, second Patch/preset schema or chemical database product. Selected release has no online lookup; future provider work requires new scope or concrete failure of this requirement. |
| D1 | latitude | Class/file layout, native widgets/window sizes, error wording and tests, deterministic sort/buffer reuse/index resolution. Use libraries directly; no speculative repository/service/factory layers. |
| D2 | latitude | FIFO/command layouts and capacity within the documented bound, module storage pool layout, bounded reset/steal implementation, smoothing/fade shape/duration within policy. Preserve ownership, note continuity, latest-wins, two-bank/128 MiB limits and tests. |
| D3 | latitude | Musical equations, interpolation, defaults/gain calibration and convenience-array editing within current catalog/parameter semantics. Neither polyphony reduction nor new user quality modes are within latitude. A fixed oversampling implementation change is allowed only with V2/V5/V8/latency evidence and explicit audible-version compatibility assessment; no silent saved-sound reinterpretation. |
| D4 | latitude | Helper byte/time/memory budgets and package layout/hooks are resource policy, not molecular identity. Start with CHEMISTRY/TOOLCHAIN defaults; adjust with measured legitimate-input, bounded-failure and installed-closure evidence. | D5 | latitude | Pin maintenance/security updates, direct SQLite queries/index layout, file naming, snapshot curation within DISCOVERY acceptance and schema. Record source/license/hash/update evidence. Existing analysis/projection/mapper semantics are versioned independently. Major framework/backend substitution needs correction evidence. |
| D6 | fixed | Decision 2026-09-18 (phase 3, #65), recorded by #66: human acceptance of the #59 pre-release found the tabbed list/selector editor unfit as a product. The native editor is rebuilt as the single-screen graph editor in ARCHITECTURE (eleven fixed typed slots activated in place, preallocated IN/OUT ports with drag cabling, runtime orthogonal cable routing, lane-style matrix, forest array editing, effective-value accent rings from engine atomics, chemistry as a modal popup in the extension build, two-token visual language with modulation accent and per-cable colours, keyboard/graph accessibility not required). | D7 | latitude | Within D6: cable colour assignment from the dynamic set, corner radius and segment routing heuristics of the orthogonal router, port geometry/hit areas, knob/fader/segment/curve/forest rendering details, lane widget layout, tooltip/precision-entry/`EDIT` table presentation, effective-value voice-selection policy and the exact ≤30 Hz timer. | D8 | fixed | Decision 2026-09-20 (phase 4, #104), recorded by #105: human acceptance of `v2.0.0-preview.3` and the `4699989` staged build found the instrument converging on metallic, bell-like results regardless of molecule. The cause is structural breadth, not a mapping bug — no unison/detune, stereo spread, per-voice drift, per-source pitch, effects tail, envelope curves or LFO shapes exist, so pads, stabs and spikes are unreachable. Architecture v3.2 in ARCHITECTURE therefore extends the catalog from seven to **twelve** types (adds `sub`, `chorus`, `delay`, `reverb`, `width`), adds the unison/spectral-shape/pitch/filter/shaper/modulator parameters listed there, defines the **post-mixer global effects tail** with its router constraints, introduces exactly two typed **audio-rate modulation inputs** (`modIn` on FM, `exciteIn` on the resonator) as the single exception to "no per-module distinct inputs", adds **E4** and the envelope-curve/LFO-shape/fade/sync modulator settings, and raises Patch caps to **16 nodes, 48 edges, 40 matrix rows, 4 envelopes** with the editor slot set growing to 16 + OUT. Patch/State versions and wire format are unchanged; the decoder gains the documented default-fill rule for parameters and E4 added after the original v1 catalog, and every previously valid patch both decodes and renders identically. Wavetables, sample import, an extensible effects rack, inter-node feedback and cycles stay excluded. Every new parameter must be reachable by the chemistry mapper under the CHEMISTRY mapper-coverage invariant, with phase-4 entries explicitly `provisional`; the deep mapping rework from the full structural vocabulary is phase 5. It supersedes the "no new module types" and "adding a new module type is outside release scope" clauses for exactly these five types. Unchanged: A2–A7 authority, A5 realtime ownership, existing parameter IDs/ranges/defaults/arities, DSP equations of existing modules, no edge enable flag, MAPPING-POLICY's ≤12 generated rows. |
| D9 | latitude | Within D8: the exact DSP realization of each new module inside the stated ranges (chorus delay-line count and modulation shape, reverb network topology, ladder-filter formulation, shaper curve equations, drift LFO shape and rate, unison detune distribution curve), the compiled representation of the global effects tail, `Layout.hpp` slot coordinates for the sub and effects slots as regenerated by `scripts/layout-slots.py`, the widget/geometry choices for the new controls and the second port anchor, tempo-sync division arithmetic, and the storage layout that keeps the widened bounds inside ≤128 MiB. Preserve the declared ids/ranges/defaults/scales/kinds/cost classes, the router constraints, the compatibility defaults and the production-path tests. |
| D10 | fixed | Decision 2026-09-22 (#146), on measured evidence from #129/#144: the phase-4 V8 CPU budget and the D8 worst-case benchmark patch as first written are not simultaneously satisfiable. With `unisonVoices` 7 on all three general source slots at 16 voices — 336 source stacks — the canonical arm64 container measured renderRatio 1.0846 after the D9 optimisation work in #144, and the specified arithmetic alone (344 M partial updates/s plus the FM operators and the rotation-delta rebuild, × the bank-crossfade factor V8 itself requires) already accounts for ≈0.46 of the 0.5 budget. A gate no current hardware can pass proves nothing, so **VERIFICATION V8's fixed worst-case patch is restated as a per-voice source-copy budget of 9**: `unisonVoices` 7 on exactly one general source (a `harmonic`), the other two general sources at the catalog default of 1. Everything else in the patch is unchanged (16 slots, 48 edges, 40 rows, sub active, both typed audio-rate inputs cabled, the full effects tail at non-zero `mix`, 16 held voices, repeated bank transitions, 2× internal rate), and `all-modules` stays a second arm that must keep passing. **No gate is lowered and no bound moves**: ratio ≤0.5, p99 < 128/48000 s, per-voice ≤(0.5 × 128/48000)/16 s, memory ≤128 MiB, `maximumUnisonVoices` 7, polyphony 16 (D3), the 2× rate (D3). No rendered sample moves, so panel digests, `cross-platform-parity-v1` and `mapping-calibration` are untouched. `docs/USER-GUIDE.md` states the load characteristic for users. Deferred to phase 5: a runtime unison budget that falls as voice count rises, and revisiting the fixed 2× internal rate for the alias-free additive source. It corrects a D8-era benchmark definition under D3/D8 and moves no gate, polyphony or unison cap. |
| D11 | fixed | Decision 2026-10-05 (#149), on measured evidence from #144: after the D9 optimisation work the D10 worst case still measures renderRatio 1.199 on the canonical container at `706b6b3`, and 0.82 even with unison removed. The residual is fixed per-voice-per-sample graph cost that the 2× internal rate doubles, which no delegated lever reaches. **VERIFICATION V8's worst-case arm is therefore a measured, published load characteristic rather than a ≤0.5 ratio gate**: it is still measured with the named evidence method, its ratio/p99/per-voice/tail figures are recorded in the verification pass and stated in `docs/USER-GUIDE.md`, and it carries a regression ceiling of renderRatio ≤1.5 on the canonical container. | D12 | fixed | Decision 2026-10-05 (phase 5, #165), implemented by #166: the bell convergence D8 addressed with breadth persists in generated patches, and the engine still has no classic oscillator, so saws, squares and pulses are unreachable by any mapper. The order is **toolbox first, mapper second**. The catalog therefore grows from twelve to **fourteen** types: **`osc`** (band-limited sine/triangle/saw/square with `pulseWidth`) and **`wavetable`** (`table`, morphable `position`), both with the existing unison and pitch blocks, both sharing the three general source slots — no slot, node-cap or bound change. The D8 exclusion "wavetables remain excluded" is lifted for **built-in tables only**: eight synthesized in-repo and twenty-four sampled from Adventure Kid Waveforms (AKWF-FREE, **CC0-1.0**, vendored in `third_party/akwf` with its licence and a hash manifest). User wavetable import, sample import and an external table path stay excluded. The `table` choice list is append-only. **Mapper-coverage invariant amended:** the two D12 types carry coverage entries with status `unmapped` until the phase-5 mapper rework replaces them, and that rework is released from "no catalog parameter may be dead for chemistry" — the rule is that curated beats complete, so parameters may stay unreachable from chemistry provided each such entry says so. **Per-change test policy for phase 5 (2026-10-05):** build plus the tests the change touches; the full V0–V11 chain, the benchmark, sanitizers, pluginval and the macOS gate run at release time in the phase's verification pass. The structural profile is computed in C++ from the Analysis graph, so the packaged helper did not change. ## Build versus buy

Count implementation, wrappers, generated glue, local patches and compatibility maintenance as owned code. Add a dependency only when it removes a meaningful owned subsystem; do not minimize dependency count in isolation.

| Responsibility | Selected implementation | Why / owned-code consequence | Realtime, license, maintenance / justified seam |
| --- | --- | --- | --- |
| Plugin formats, native UI, host parameters/state transport | Retain pinned JUCE | Working Linux VST3/Standalone foundation; one framework covers UI/attachments/host lifecycle and portable AU path. iPlug2's reviewed [CMake Linux limitation](https://iplug2.github.io/docs/md_cmake.html) and separate CLAP/UI/state stacks provide no demonstrated net saving. | JUCE AGPL/commercial terms; no fork. Domain/state boundary protects semantics, not a wrapper per JUCE type. |
| DSP primitives | JUCE ADSR/TPT/delay/oversampling/limiter; small bespoke harmonic/FM/noise/musical composition | Existing processors usable. Direct sin/tanh arithmetic needs no wrapper merely for stylistic compliance. chowdsp/Surge add integration without a demonstrated missing required primitive. | Prepare allocating primitives off audio; pin upstream, preserve notices and saved sound. No new DSP facade. |
| DAG compiler/matrix | Bespoke bounded values and dispatch over public catalog | Small product-specific per-voice topology. AudioProcessorGraph has general AudioProcessor/node lifecycle beyond needed fixed dispatch; it would not remove our Patch validation, matrix or transition semantics. | No dynamic runtime graph; deterministic off-thread compiler. Public Patch is the actual seam. |
| Polyphony/MIDI/transactions | Bounded scheduler + JUCE MIDI/AbstractFifo, two prepared banks | Pinned JUCE Synthesiser::processNextBlock holds ScopedLock; using it directly violates required no-lock render. Own bounded scheduling/coalescing only. | No RT reclamation. Capacity/layout delegated, RT proof required. No general event framework. |
| JSON/state/files/WAV/process/tests | Direct JUCE and Python stdlib unittest/subprocess | Existing production codec and small schema need bounded decoding, not replacement with a second serialization framework. Reuse filesystem/temp/atomic-replace facilities. | JSON and files off audio. Narrow process-tree OS calls only for cancellation JUCE cannot provide. |
| Structural chemistry/name parsing | RDKit Python + OPSIN CLI in private child | Mature canonicalization/descriptors/name parsing, single interpreter and strict protocol. Avoid parallel heuristic/C++ backend and custom name parser. | BSD-3-Clause/MIT plus transitive notices; private Python/JDK licenses. Analysis is stable protocol seam. |
| Sonic projection/generation | Bespoke versioned sparse mapping | Product-specific musical correspondence; no library can choose it. No generic rules engine. | Off audio; traces/tests and exact generated Patch protect later mapper upgrades. |
| Discovery data | Bounded Wikidata structured-data snapshot, cross-checked structure evidence | CC0 names/identifiers are useful discovery metadata. Avoid Wikipedia prose/media, full KG and bulk biomedical corpus. [DISCOVERY](DISCOVERY.md) compares sources and defines acceptance. | No runtime fetch; per-record provenance and source archive. Provider-to-record adapter is justified by external schema churn. |
| Discovery search/index | SQLite via existing helper's Python sqlite3 | Standard indexed exact/prefix search and transactions remove custom index/database code; no C++ SQL wrapper, server, ORM or FTS engine needed. | Off audio; SQLite [public-domain distribution](https://www.sqlite.org/copyright.html). Pin actual bundled SQLite version/options with helper. |
| Discovery cache/generated results | Separate SQLite metadata cache plus normal `.iupacpatch` files | Cache searchable metadata; keep generated sounds file-backed and disposable. User presets use the same State codec and files, outside cache eviction. | Transactional metadata + atomic files; no monolithic user-content database. Shared State is the sound seam. |
| Runtime online discovery | None selected | Offline snapshot satisfies bounded required browser scope; avoids extra HTTP/privacy/provider failure subsystem. Optional future adapter policy is specified, not a planned feature. | No silent input transmission. Reproducible fixtures remain release gates. |
| Packaging | PyInstaller onedir and private OpenJDK/jlink baseline | Mature closure tools replace a custom freezer/JVM integration. Delegate module set/hooks; validate installed artifacts. | Native packaging, runtime/source notices; no launch extraction, global environment mutation or external language runtime. |
| Audio metrics/plugin validation | NumPy over production WAV; pinned pluginval | Standard FFT/reductions and host stress replace custom FFT/scanner. Keep the small documented pluginval Linux patch until upstream removes need. | Test-only dependencies, GPL pluginval not linked into product. No second render engine. |

## Changing a fixed decision

A fixed decision changes only with concrete implementation evidence of contradiction, infeasibility, material safety/realtime trouble or inability to satisfy another controlling requirement. Record the affected decision, reproducer, evidence, alternatives, migration impact and the smallest sufficient correction, and update the authoritative docs and tests in the same change. Latitude work and P1 calibration need recorded implementation evidence, not renewed approval.
