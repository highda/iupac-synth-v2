## Headless interface

There is one `iupac-cli` executable. The chemistry-disabled build provides:

- `inspect --stage catalog`: canonical module/parameter/modulation descriptors.
- `inspect --patch FILE --stage patch|compiled` and `inspect --snapshot FILE --stage effective`: shared production decoding/compilation and resolved parameters/routes, including supplied control values.
- `render --snapshot FILE --midi FILE --sample-rate 48000 --block-size 128 --output FILE.wav`: production engine, JSON event stream with integer sample offsets, stereo float32 WAV and manifest. Static controls or explicitly timestamped control events; no chemistry dependency.
- `verify-panel --panel FILE --output-dir DIR`: authored-patch panels through production functions with gate reports and graph signatures. Failure is nonzero and names fixture/rule.

The later chemistry-enabled build adds `analyze --mode name|smiles --input TEXT`, `inspect --analysis FILE --stage sonic|mapping`, and chemical-panel support to `verify-panel`. Generation writes a normal snapshot for the same render operation. No separate chemical renderer or testing backend. Exact option parsing is delegated; keep these operations scriptable with bounded inputs.

The extension also exposes `discover --query TEXT`, selected-record/provenance inspection and bounded cache inspection/clear, through the production helper; generation yields the same normal snapshot. Preset listing/loading remains ordinary synth file operations. Exact flags are delegated.

Successful CLI output is JSON on stdout, diagnostics on stderr; cap all inputs. Include schema/mapper/backend versions in output. Production decoding and error policy is shared with plugin state; do not maintain an independently permissive CLI schema.

### V4 distance definition (freeze before calibration)

For each note render a 2 s held note plus 1 s release, 48 kHz, velocity 100, default controls. Remove fixed reported latency. From active 2 s, normalize non-silent waveform to RMS 0.1 for spectral comparison (reject V5 silence first); mono energy spectrum is the **sum of L/R powers**, not a cancelling L+R fold. Use Hann STFT, 2048 samples, hop 512; sum powers in 24 logarithmic bands 40–16000 Hz, average frames, convert to dB with 1e-12 power floor and subtract band mean. Distance spectral term = mean absolute band dB difference / 24, clipped to [0,1]. Envelope term = mean absolute difference between 20 equal-duration bins of stereo RMS normalized by each note's peak RMS. Total distance = 0.75 spectral + 0.25 envelope. Freeze calculation in one NumPy tool and test it with identical/gain-scaled/time-envelope/spectral synthetic signals. These synthetic signals validate the metric, never substitute for production renders.

Thresholds are deliberately anti-collapse engineering checks, not a perceptual proof. Report nearest pairs, graph-signature occupancy, centroid/flatness, loudness and alias spectra diagnostically. Do not optimize all pairs to a universal distance or claim log-band separation implies musical quality. Plot spectra of FM/high-note/drive stress against a higher-rate diagnostic render to investigate aliasing; no arbitrary universal alias dB pass threshold in this release. Material demonstrated alias/click defects require correction even when numeric gates pass.

## Human evidence and release condition

Host, listening, visual and physical MIDI cases are human checks: record exact candidate/setup, expected/actual result and status. Automated gates never stand in for them.

CI is source-gated: the Linux Actions workflows (TSan, arm64 package/V10) run for pull requests touching source paths, and the macOS arm64 workflow is dispatched on the candidate commit for releases; `prerelease.yml` runs both delivery workflows at the release commit. The mapper-coverage invariant ([CHEMISTRY](CHEMISTRY.md#mapper-coverage-invariant)) is enforced by the `mapping-coverage` ctest in every build, chemistry-ON and OFF; a catalog parameter with no entry in `data/mapping-coverage.json`, an entry with no drivers, or an entry naming a parameter the catalog does not have, fails the gate. A release requires V0–V11 and no open required defect. Human failures become bounded defects.

## Regression requirements

#7 adds production same-destination opposing-row/permutation tests (normalize base, sum all contributions, clamp once), all matrix sources/destinations including disabled rows, actual integer-latency verification, fresh voice reuse/steal/CC120/zero-block MIDI cases, documented output-rate filter ceiling and output chain without a hidden tanh stage. #11 adds note-preserving scalar/array/matrix edits, discrete-mode transitions and bounded reclamation/reset-cost proof. #12 adds shared pre-parse byte/depth/container limits and exact nondefault-control preset/project round trips; #9 bounds file reads. The audit's inspected counterexamples are covered by production-path tests.

State/Patch JSON initial limits: 1 MiB per document/input and nesting depth 32, with fixed structural caps and bounded strings/metadata containers. Reject oversized/unbounded parse work before JUCE decoding. Limit/decode behavior is shared by file/plugin/CLI, with bad UTF-8, oversized coefficient arrays and nested optional provenance tests. Values/formats stay compatible; no second codec.

Performance numbers, timing defaults and helper/cache resource limits are release verification/implementation policy as classified in [DECISIONS](DECISIONS.md). Changes require named measurements and retained compatibility/acceptance; they cannot lower V3/V4 or remove available required checks. Readable code/call-path inspection complements instrumented behavior; source-shape assertions alone are not proof.
